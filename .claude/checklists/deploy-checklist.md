# Checklist — Deploy

- [ ] Migrations novas revisadas — reversíveis ou com plano de rollback claro
- [ ] Variáveis de ambiente/secrets necessários documentados e configurados no destino
- [ ] Build de produção passa sem erro
- [ ] Nenhum log de debug remanescente em código de produção
- [ ] Healthcheck respondendo corretamente
- [ ] Rollback plan claro (versão anterior disponível/marcada)
