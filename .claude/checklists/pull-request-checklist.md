# Checklist — Pull Request

- [ ] Spec vinculada (`.claude/specs/<slug>/` ou `docs/specs/<slug>/`)
- [ ] Descrição do PR segue `.claude/templates/pr-template.md`
- [ ] Todos os checklists relevantes deste projeto passados
- [ ] `/review` rodado sem achados críticos/altos pendentes
- [ ] Build e testes passam localmente
- [ ] `git status` revisado — sem arquivo indevido staged (segredos, artefatos de build, dependências)
- [ ] Screenshots incluídos se houver mudança de interface
- [ ] Commits com mensagens claras, sem "wip"/"fix" genérico como mensagem final
