# Checklist — Release

- [ ] Todas as specs incluídas na release estão arquivadas em `docs/specs/`
- [ ] ADRs relevantes registrados em `docs/decisions/`
- [ ] `.claude/context/tech-stack.md` atualizado se alguma dependência estrutural mudou
- [ ] Changelog/notas de release descrevem o que mudou em termos de valor, não só commits técnicos
- [ ] Sem regressão conhecida em funcionalidades já existentes (smoke test das mais críticas, se houver mudança compartilhada)
